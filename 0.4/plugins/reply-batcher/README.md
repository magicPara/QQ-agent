# 群聊定时合并回复

这是 QQ Agent 的确定性插件。启用后，群聊中的文本 `send_message` 会先进入该群自己的缓存队列，到达间隔后合并为一条消息，每段单独 @ 对应收件人，段落之间空一行。

回复多人时，每人分别调用 `send_message`，用 `atUserId` 指定 QQ 号，或用 `replyToMessageId` 引用原作者。只有唯一普通消息触发者时才自动补充目标；多人且没有明确目标时拒绝入队，让模型补齐参数。数组中的所有文本属于同一收件人，不按数组位置推测回复对象。

在控制台的「插件」页设置：

- `all`：所有群使用默认间隔；`groupRules` 可覆盖单个群。
- `listed`：只处理 `groupRules` 中列出的群，其他群保持原行为。
- `groupRules` 格式：`群号=间隔毫秒`，多个规则用逗号分隔，例如 `123456=5000,234567=30000`。写成 `群号=off` 可关闭指定群。

插件只处理群聊，私聊不延迟。发送、限频、去重和 OneBot 协议调用仍走核心原有路径。
